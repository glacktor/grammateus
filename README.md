# Grammateus

*γραμματεύς — «писарь» по-гречески.*

Пишешь и не думаешь, какая раскладка включена. Grammateus — локальный автопереключатель EN/RU для macOS: если набрал `ghbdtn`, он сам исправит на «привет» и переключит раскладку.

Весь код в одном файле [`main.swift`](main.swift). Никакой сети. На диск пишутся только настройки. В полях паролей программа не видит ничего: macOS включает secure input.

## Что умеет
- **Автоисправление** после пробела, Enter или Tab:
  - `ghbdtn` → «привет», `руддщ` → «hello»;
  - `f rfr ltkf` → «а как дела»: однобуквенный предлог исправляется вместе со следующим словом;
  - `ghbdtn,` → «привет,»: знаки по краям остаются как набраны.
- **Не трогает нормальные слова** и короткие английские вроде `git`, `vs`, `cd`, `ok`, `api`.
- **Backspace сразу после исправления** откатывает его, и слово запоминается: больше его не тронет.
- **Двойной Shift**: откатить исправление, перевести последнее слово или просто сменить язык.
- **Индикатор EN/RU** в меню-баре. Через меню можно выключить исправление, исключить текущее приложение или включить запуск при входе.
- В терминалах и IDE по умолчанию выключен: Terminal, iTerm, Warp, Ghostty, kitty, VS Code, Cursor, Zed, Xcode, JetBrains.

Работает с любыми английской и русской раскладками (US, British, «Русская», «Русская – ПК»): буквы берутся из системы.

## Установка

### Вариант 1: готовое приложение
1. Скачай `Grammateus.zip` из [Releases](../../releases), распакуй и перенеси `Grammateus.app` в «Программы».
2. Запусти. macOS скажет, что разработчик не проверен (приложение не подписано платным сертификатом Apple). Открой System Settings → Privacy & Security → «Всё равно открыть».
3. Выдай права в System Settings → Privacy & Security: **Универсальный доступ** и **Мониторинг ввода**.
4. В меню-баре появится `EN` или `RU`, всё готово. Пока прав нет, там горит `⚠︎`.

### Вариант 2: собрать самому из исходников (если не хочешь доверять чужому бинарнику)
Нужны Xcode Command Line Tools: `xcode-select --install`.
```bash
git clone https://github.com/glacktor/grammateus.git
cd grammateus
./build.sh --install
```
Затем выдай те же два права.

Самопроверка логики (доступ к клавиатуре не нужен):
```bash
./build/Grammateus.app/Contents/MacOS/Grammateus --selftest
```

> После каждой пересборки macOS сбрасывает права: в Privacy & Security нужно снова включить Grammateus.

## Как это работает
1. **Клавиши, а не буквы.** Программа запоминает физические клавиши слова и по раскладкам системы (`UCKeyTranslate`) получает обе версии: `ghbdtn` и `привет`.
2. **Решение на границе слова.** Пробел или Enter задерживается на миллисекунды. Если нужно исправить, программа стирает слово, печатает правильное, отправляет твой пробел и переключает раскладку. Автозамена приложения не успевает влезть.
3. **Правило.** Исправляет, только если набранное **не** слово в текущем языке, а вариант в другой раскладке — слово. Проверяет встроенный словарь macOS (`NSSpellChecker`), локально.
4. **Защиты.**
   - Алфавит должен совпадать с языком.
   - Своё слово проверяется мягко, замена строго: двухбуквенные заменяются только из белого списка.
   - Слова КАПСОМ проверяются строчными.
   - Буфер сбрасывается на клики, стрелки, ⌘/Ctrl/⌥ и смену приложения.

## Удаление
Выход в меню значка, затем удали `Grammateus.app` и убери его из Privacy & Security.
